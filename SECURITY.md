# Security and private findings

Do not post live asset addresses, credentials, raw captures, customer reports or unpatched product vulnerability details in public issues. Contact the repository owner privately through the published maintainer contact once this project is hosted. No project mailbox or response SLA exists yet.

For a suspected vulnerability in an upstream product, use that upstream's current security reporting process. For findings affecting an assessed organization, follow the engagement's reporting contacts. This project does not provide incident response services or certify equipment safety.

See docs/ARCHITECTURE.md for trust boundaries and known limitations. Security reports about this starter should include a sanitized reproducer and version/commit without real customer data.
