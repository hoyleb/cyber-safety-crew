# Contributing

Start with AGENTS.md and the roadmap. Keep PRs focused on one adapter, profile or capability. Include sanitized fixtures and relevant tests for new formats. State the upstream versions exercised and distinguish synthetic contracts from real-format compatibility evidence.

Propose a device check with its purpose, supported product/version, exact traffic, runtime/tool requirements, expected effects, failure modes, evidence schema and lab validation. Field execution is not enabled merely by adding a profile entry.

Keep assessment data private. Submit general product fixes upstream rather than building a large private patch set. Before the first public community release, the repository owner must publish maintainers, a private reporting channel and release ownership.
